# MrMiaw — Roblox GFX Artist Portfolio

Single-page portfolio and commission site for MrMiaw, a Roblox GFX artist.
Built with Next.js (App Router), TypeScript, Tailwind CSS, Lenis smooth
scrolling, and Lucide icons. Deploys on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Checks

```bash
npm run lint
npm run build
```

## Project notes

- Original artwork lives outside this repo in `/GFX` and is never modified.
  Web-ready copies are committed under `public/gfx`.
- Commissions convert through the Discord server: https://discord.gg/C99tjr5Txq
- Art direction is documented in `DESIGN.md`.
- Project-local skills live in `.opencode/skills/`.
